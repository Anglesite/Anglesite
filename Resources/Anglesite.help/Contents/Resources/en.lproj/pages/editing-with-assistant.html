Editing with the assistant

Alongside editing pages directly, you can ask Anglesite to change your site using plain language — no code required.

The chat panel

Show or hide the chat panel with View ▸ Show Chat (⌃⌘K) — it's a side panel, hidden until you open it. Type what you want to change and the assistant takes care of the rest. You can ask for anything from a wording tweak to a layout change, and Anglesite will figure out which files to edit.

By default the assistant runs entirely on-device using Apple Intelligence. In Settings ▸ Agents you can instead point it at a custom LLM endpoint or a connected agent — see Settings.

Edits appear in your site

When the assistant finishes, the changes are written to your files and the live preview updates automatically. An overlay highlights what changed directly in the preview so you can see the result at a glance.

Every edit is tracked

Each successful edit appears as a row in the chat showing the file that changed and how long ago. Each row has an Undo button so you can reverse any edit without leaving the app.
