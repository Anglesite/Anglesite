Keyboard shortcuts

Quick-reference shortcuts for common actions in Anglesite.

General

  • ⌘` — cycle between open site windows
  • ⌥⌘D — show the Debug pane
  • ⌘, — open Settings
  • ⌘? — open Anglesite Help

File

  • ⇧⌘N — New Site…
  • ⇧⌘L — New Link Post…
  • ⌘O — Open Site…
  • ⌘S — Save
  • ⌘P — Print…

Edit

  • ⌘D — Duplicate the selected item
  • ⌘F — Find…
  • ⌘G / ⇧⌘G — Find Next / Find Previous
  • ⌥⌘F — Find & Replace…
  • ⇧⌘F — Search Site…

Format (with a markdown or visual editor focused)

  • ⌘B / ⌘I — Strong / Emphasis
  • ⌥⌘1–⌥⌘6 — Heading 1–6
  • ⌘K — Add Link…

Page

  • ⌘N — New Page…

View

  • ⌘1 / ⌘2 / ⌘3 — Preview / Editor / Graph pane
  • ⌃⌘K — Show/Hide Chat
  • ⌥⌘I — Show/Hide Inspector
  • ⌘R — Reload Preview
  • ⌃⌘← / ⌃⌘→ — Back / Forward in preview history
  • ⌘0 / ⌘+ / ⌘− — Actual Size / Zoom In / Zoom Out

Website

  • ⇧⌘, — Website Settings…
  • ⇧⌘P — Publish…
  • ⌥⌘R — Restart Dev Server
