Live preview

Each site window shows your site running live so you can see exactly what you're building.

A live view of your site

The main pane of every site window is a live preview of your running site. It looks and behaves just like your site does in a browser — including navigation between pages.

Preview is one of three main panes, switched with View ▸ Preview / Editor / Graph (⌘1, ⌘2, ⌘3). Selecting a page or post in the Navigator sidebar always brings you back to Preview, since pages render rather than open as text — see Editing pages directly.

It starts and stops with the window

Opening a site starts its preview server automatically. Closing the window stops it. Each window is independent, so you can have multiple sites open at the same time without them interfering with each other.

Reloading

You don't need to reload manually. When you or the assistant make changes and save files, the preview refreshes automatically so you always see the current state of your site.
