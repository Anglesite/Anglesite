Accounts and setup

Connect your GitHub and Cloudflare accounts so Anglesite can back up and publish your site.

GitHub

Your site's Source folder is an ordinary Git repository. Anglesite pushes to GitHub itself using a personal access token — add one in Settings ▸ Advanced ▸ Credentials, or when a publish or backup prompts you for one.

Create a fine-grained token at github.com/settings/tokens scoped to All repositories with: Contents: Read and write, Administration: Read and write (needed to create a new repository the first time you publish), Repository security advisories: Read, and Dependabot alerts: Read (the last two let Anglesite show a site's open security reports).

Cloudflare

The easiest way to connect Cloudflare is to sign in from a Deploy sheet — Anglesite stores the credential and refreshes it automatically, and every Cloudflare-backed feature (deploy, domains, analytics, and more) uses it first.

If you'd rather not sign in, you can instead paste a Cloudflare API token in Settings ▸ Advanced ▸ Credentials; it's only used when no sign-in is connected.

Stored securely

Your credentials are stored in the macOS Keychain — not in any file inside your site folder.
